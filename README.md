# Ahmet Efe Şensoy

FRC, robotik/otonomi ve mühendislik simülasyonları üzerinde çalışıyorum. Algoritmaları çalıştırılabilir demolar, ölçümler ve testlerle anlatmayı amaçlıyorum. Havacılık/İHA sistemleri de ilgi alanlarım arasında.

I work on FRC, robotics, autonomy and engineering simulation. I document projects through runnable demos, measurements and tests. My broader interests include UAV systems and physical simulation.

## FRC

- **[FRC AutoLab](https://github.com/ahmetefesensoy/frc-autolab)** — Otonomlar için deterministik simülasyon, hata enjeksiyonu ve replay. / Seeded autonomous testing with fault injection and replay; an early working MVP.
- **[2018 Dynamic Autonomy](https://github.com/ahmetefesensoy/2018-offseason)** — POWER UP için Jetson/ROS 2 rota planlama, NT4 bağlantısı ve roboRIO kontrolü. / A personal POWER UP experiment with temporal planning and a bounded robot command link; simulation tested, hardware unverified.
- **[Adaptive Swerve Framework](https://github.com/ahmetefesensoy/FRC-dynamic-swerve-config-for-chassis-ratio)** — Şasi geometrisine uyarlanan swerve kinematiği ve REV/CTRE adaptörleri. / Geometry-aware swerve code with vendor adapters.
